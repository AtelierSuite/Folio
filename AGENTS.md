# Repository

- `App` holds Folio for iOS, iPadOS and macOS. Read `App/AGENTS.md` before working there.
- `Assets` holds the App Store screenshot composer, the app icon source and other resources.

# Commits

1. Commit as you go: commit after every change that builds and runs, one logical change per commit.
2. Do not bundle unrelated changes; if a piece of work touches several things, split it into one commit per change.
3. Commit messages are a single line, with no body, no bullet lists and no trailers or attribution footers.
